Bookmark Setup Planner

You save things on X because they matter to you, and then (if you're like me) you never see them again. This sets up a small machine that pulls your bookmarks on a schedule, sorts each one into topics you choose, and writes it up as a note in your Obsidian vault or any folder you like.

Plan the setup here, download one file, and the setup wizard takes it from there.

This page never asks for a password, cookie, or API key. The wizard asks for those in hidden prompts on your own computer, checks each one, and stores it there.

01Before you start

Tick these off as you go. (They're remembered in this browser only.)

02Topics and where they go

Every bookmark goes to the topic it fits best. One that fits none of them gets skipped, which is a feature: it's how the junk stays out of your vault.

Start from a preset or two. The ones with a ✓ were tuned against real review answers; the rest get sharpened by the wizard.

Where notes will land

03Who writes the notes

Claude Haiku reads each bookmark (threads, linked articles, even text in images) and writes the note: a summary, the key points, a quote or two, and a how-to when a post shares a recipe or tool.

04When it runs

Got a big backlog? Each run takes up to that many unprocessed bookmarks, newest first, so the backlog clears a batch per run. The computer needs to be on with you logged in (a locked screen is fine); if it's asleep, it wakes, and if it's off, the run happens at your next login.

05Run the wizard

Save your plan, then run setup with it. The wizard checks your tools, asks for your X cookies and keys (hidden), confirms each one works, installs the schedule, and offers a five-bookmark test drive into a preview folder.

Your computer:

Run it from the folder you downloaded the project to, and point --answers at wherever my-setup.json landed.
